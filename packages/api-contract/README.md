# API contract

`openapi.json` is the exported REST schema of the running application, generated by
`scripts/export_openapi.py` and committed so that changes to the API surface are visible in review and
pinned for clients (the web console today, the desktop shell later).

```bash
python3 scripts/export_openapi.py            # regenerate after changing a route
python3 scripts/export_openapi.py --check    # what CI runs
```

`tests/unit/test_api_contract.py` fails when the committed file and the app disagree, so the contract
cannot drift silently. Paths are versioned by the `/api` prefix plus the `X-Natasha-Version` header
convention described in `docs/api.md`; the schema itself carries no credentials and no server-side
secrets — it is generated from route signatures only.
